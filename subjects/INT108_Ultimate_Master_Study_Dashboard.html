🎯 Top 15 High-Yield Examiner Viva Voce Q&A

1. Is Python interpreted or compiled?
Both. Source code (.py) is compiled to bytecode (.pyc), which is then interpreted by the Python Virtual Machine (PVM).
2. What is the difference between 'is' and '=='?
'==' checks value equality (content), whereas 'is' checks memory identity (id(a) == id(b)).
3. What is the LEGB Rule?
The variable scope lookup order: Local -> Enclosing -> Global -> Built-in.
4. Differentiate between shallow copy and deep copy.
Shallow copy creates a new container with references to original child items; deep copy recursively duplicates all nested objects.
5. What is the Mutable Default Argument Trap?
Default arguments like [] are created once at definition time, persisting state across multiple calls. Fix with arg=None.
6. What is Name Mangling in Python OOP?
Prefixing attributes with double underscore __var transforms it to _ClassName__var to prevent collision in subclasses.
7. Why should you always use 'with open() as f:'?
It utilizes the Context Manager protocol (__enter__ and __exit__), guaranteeing deterministic file descriptor closing even on errors.
8. What is Pickling and Unpickling?
Pickling (pickle.dump) serializes Python objects to binary; Unpickling (pickle.load) restores objects from binary.
9. What does the loop 'else' clause do?
Executes if and only if the loop terminates normally without hitting a 'break' statement.
10. What is the result of 2 ** 3 ** 2?
512 (Exponentiation is evaluated RIGHT to LEFT: 3**2 = 9, then 2**9 = 512).
11. What is the Global Interpreter Lock (GIL)?
A mutex in CPython that restricts bytecode execution to one native thread at a time, ensuring thread-safe reference count management.
12. How does Python's Garbage Collection work?
Primary mechanism is Reference Counting; secondary is Generational Cyclic GC across 3 generations for reference cycles.
13. What is C3 Linearization MRO?
The deterministic algorithm Python uses to resolve base class inheritance orders in multiple inheritance hierarchies.
14. What are __slots__?
Defines a fixed tuple of attribute names, eliminating instance.__dict__ to save memory and accelerate attribute access.
15. Why is unpickling untrusted data dangerous?
Deserialization via pickle.load() can execute arbitrary malicious code if the payload overrides __reduce__().
