🔬 Unit I: Solid State Physics, Energy Bands & Hall Effect

1. Hall Effect Derivation & Force Balance

Force Balance:       e · E_H = e · v_d · B  ===>  E_H = v_d · B
Current Density:     J = n · e · v_d = I / (w · t) ===> v_d = I / (n · e · w · t)
Hall Voltage:        V_H = E_H · w = (B · I) / (n · e · t)
Hall Coefficient:    R_H = 1 / (n · e)  ===>  V_H = (R_H · B · I) / t
Carrier Mobility:    μ = σ · R_H

2. Fermi-Dirac Distribution Function

f(E) = 1 / [ 1 + exp((E - E_F) / (k_B · T)) ]
• At T = 0 K: f(E) = 1 (E < E_F), f(E) = 0 (E > E_F)
• At T > 0 K: At E = E_F, f(E_F) = 0.5 (50% probability of occupancy)

⚡ Unit II: Fundamentals of Electricity & Devices

1. Circuit Laws & Rectifier Formulas

• Voltage Division: V₁ = V_in · [ R₁ / (R₁ + R₂) ]
• Current Division: I₁ = I_total · [ R₂ / (R₁ + R₂) ]
• Half-Wave Rectifier: Efficiency η = 40.6%, Ripple Factor γ = 1.21, PIV = V_m
• Full-Wave Bridge:    Efficiency η = 81.2%, Ripple Factor γ = 0.482, PIV = V_m

2. Optical Fiber Numerical Aperture (NA)

• Numerical Aperture:  NA = sin(θ_a) = √(n₁² - n₂²) = n₁ √(2Δ)
• Acceptance Angle:    θ_a = arcsin(NA)
• Fractional Change:   Δ = (n₁ - n₂) / n₁

🔢 Unit III: Number Systems & Logic Gates

1. Gray Code Conversions

• Binary to Gray: G_n = B_n, G_i = B_(i+1) ⊕ B_i
• Gray to Binary: B_n = G_n, B_i = B_(i+1) ⊕ G_i

2. Universal Gate Synthesis (NAND Only)

• NOT:  A' = (A · A)'                         [1 NAND]
• AND:  A · B = ((A · B)')'                   [2 NANDs]
• OR:   A + B = (A' · B')'                    [3 NANDs]
• XOR:  A ⊕ B = ((A · (AB)')' · (B · (AB)')')' [4 NANDs]

🎛️ Unit IV: Combinational Logic Circuits

1. Full Adder Boolean Equations

• Sum:        S = A ⊕ B ⊕ C_in
• Carry Out:  C_out = A·B + C_in·(A ⊕ B)
Implemented with exactly 2 Half Adders and 1 OR Gate.

2. 2-Bit Magnitude Comparator Equations

Let x₁ = (A₁ ⊕ B₁)', x₀ = (A₀ ⊕ B₀)':
• (A = B) = x₁ · x₀
• (A > B) = A₁·B₁' + x₁·A₀·B₀'
• (A < B) = A₁'·B₁ + x₁·A₀'·B₀

🔄 Unit V: Sequential Logic Circuits

1. Flip-Flop Characteristic Equations

• SR Flip-Flop: Q_next = S + R'·Q        (Forbidden state: S=1, R=1)
• JK Flip-Flop: Q_next = J·Q' + K'·Q     (Toggle at J=1, K=1)
• D Flip-Flop:  Q_next = D               (Data / Delay storage)
• T Flip-Flop:  Q_next = T ⊕ Q           (Toggle / Frequency Divider)

2. Master-Slave JK Race-Around Resolution

• Master FF: Enabled on Clock HIGH (CLK = 1), samples J and K inputs.
• Slave FF:  Enabled on Clock LOW (CLK' = 1), transfers Master state to Q.
• Isolates inputs from outputs, completely eliminating race-around toggling.

🤖 Unit VI: Arduino Microcontroller & Sensors

1. Arduino UNO Hardware Specs

• Microcontroller: ATmega328P (16 MHz Clock, 32KB Flash, 2KB SRAM)
• Digital Pins:    14 Pins (PWM on ~3, 5, 6, 9, 10, 11)
• Analog Inputs:   6 Pins (A0-A5), 10-bit ADC (Resolution = 5V / 1023 = 4.887 mV)

2. Ultrasonic Sensor Distance Formula

Distance d = (Speed of Sound × Time T) / 2
Distance d = (0.034 cm/μs × T μs) / 2 = (T / 58) cm
