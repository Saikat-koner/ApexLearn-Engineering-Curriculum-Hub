📐 Unit I: Matrix Methods, Linear Systems & Eigenvalues

1. Rouché-Capelli System Consistency Theorem

Augmented Matrix: [A | B]
• If rank(A) != rank([A|B])         ===> Inconsistent (No Solution)
• If rank(A) == rank([A|B]) == n    ===> Consistent (Unique Solution)
• If rank(A) == rank([A|B]) = r < n ===> Consistent (Infinite Solutions, n-r free parameters)

2. Characteristic Equation & Invariants

|A - λI| = λ³ - (Trace A)λ² + (M11 + M22 + M33)λ - det(A) = 0
• Sum of Eigenvalues   = Trace(A)
• Product of Eigenvalues = det(A)
• Cayley-Hamilton: A³ - c1*A² + c2*A - c3*I = 0 ===> A⁻¹ = (1/c3)(A² - c1*A + c2*I)

📈 Unit II: Differential Calculus & Applications

1. Leibniz's n-th Derivative Theorem

(u·v)ₙ = uₙv + ⁿC₁ uₙ₋₁v₁ + ⁿC₂ uₙ₋₂v₂ + ... + ⁿCᵣ uₙ₋ᵣvᵣ + ... + u vₙ

2. Indeterminate Forms & Transformations

• 0/0 and ∞/∞ : Directly apply L'Hôpital lim [f'(x) / g'(x)]
• 0 · ∞       : Rewrite as f(x) / (1/g(x)) [0/0 form]
• 1^∞, 0^0, ∞⁰ : Take natural log ln(y) = g(x) ln(f(x)), find limit L, result is eᴸ

🔄 Unit III: Fundamentals of Integral Calculus

1. King's Property & Symmetry

∫ₐᵇ f(x) dx = ∫ₐᵇ f(a + b - x) dx
∫₋ₐᵃ f(x) dx = 2 ∫₀ᵃ f(x) dx (if Even) | 0 (if Odd)

2. Wallis' & Gamma Reduction Formula

∫₀^(π/2) sinᵐ x cosⁿ x dx = [ Γ((m+1)/2) · Γ((n+1)/2) ] / [ 2 · Γ((m+n+2)/2) ]

🌐 Unit IV: Multivariate Differentiation & Extrema

1. Euler's Theorem on Homogeneous Functions

If u = f(x, y) is homogeneous of degree n:
• First Order:  x (∂u/∂x) + y (∂u/∂y) = n u
• Second Order: x² (∂²u/∂x²) + 2xy (∂²u/∂x∂y) + y² (∂²u/∂y²) = n(n - 1) u
• Composite:    x uₓ + y uᵧ = n [F(u) / F'(u)] = G(u)

2. Two-Variable Extrema (rt - s²)

Let r = f_xx, s = f_xy, t = f_yy evaluated at stationary point (a, b):
• Δ = rt - s² > 0 and r > 0 ===> LOCAL MINIMUM
• Δ = rt - s² > 0 and r < 0 ===> LOCAL MAXIMUM
• Δ = rt - s² < 0           ===> SADDLE POINT
• Δ = rt - s² = 0           ===> INCONCLUSIVE (Higher-order testing required)

🧊 Unit V: Multivariable Integration & Jacobians

1. Change of Order of Integration

Vertical Strip (dy dx)  ---> Horizontal Strip (dx dy)
1. Sketch boundary equations x=a, x=b, y=f1(x), y=f2(x).
2. Shade region R and locate vertices.
3. Draw horizontal strip: Left x=g1(y) to Right x=g2(y), Bottom y=c to Top y=d.

2. Jacobians of Transformation

• Polar:       x = r cos θ, y = r sin θ   ===> dx dy = r dr dθ
• Cylindrical: x = r cos θ, y = r sin θ, z ===> dV = r dr dθ dz
• Spherical:   x = ρ sin ϕ cos θ, y = ρ sin ϕ sin θ, z = ρ cos ϕ ===> dV = ρ² sin ϕ dρ dϕ dθ

🌊 Unit VI: Fourier Series & Harmonics

1. Euler's Fourier Formulas in [-L, L]

f(x) = a₀/2 + ∑ [ aₙ cos(nπx/L) + bₙ sin(nπx/L) ]
• a₀ = (1/L) ∫₋ᴸᴸ f(x) dx
• aₙ = (1/L) ∫₋ᴸᴸ f(x) cos(nπx/L) dx
• bₙ = (1/L) ∫₋ᴸᴸ f(x) sin(nπx/L) dx

2. Half-Range Expansions & Parseval's Identity

• Half-Range Cosine Series (Even): bₙ = 0, a₀ = (2/L)∫₀ᴸ f(x)dx, aₙ = (2/L)∫₀ᴸ f(x)cos(nπx/L)dx
• Half-Range Sine Series (Odd):   a₀ = 0, aₙ = 0, bₙ = (2/L)∫₀ᴸ f(x)sin(nπx/L)dx
• Parseval's Identity: (1/L) ∫₋ᴸᴸ [f(x)]² dx = a₀²/2 + ∑ (aₙ² + bₙ²)

🎯 Top 50 Master Viva Voce Questions & Answers

#Viva Voce QuestionExact High-Yield Answer
1 What is the rank of a matrix? Maximum number of linearly independent row (or column) vectors, equivalent to the order of the highest non-vanishing minor.
2 State Cayley-Hamilton Theorem. Every square matrix satisfies its own characteristic equation: P(A) = 0. Used to calculate matrix inverses and powers.
3 What are the preconditions for Rolle's Theorem? (1) f(x) is continuous on [a,b], (2) f(x) is differentiable on (a,b), (3) f(a) = f(b).
4 State Euler's Theorem on Homogeneous functions. If u is homogeneous of degree n in x and y: x (∂u/∂x) + y (∂u/∂y) = n u.
5 What is a saddle point? A stationary point where the discriminant rt - s² < 0; the surface curves up in one direction and down in another.
6 What value does a Fourier series take at a point of jump discontinuity? The arithmetic mean of left-hand and right-hand limits: [ f(x₀⁺) + f(x₀⁻) ] / 2.
