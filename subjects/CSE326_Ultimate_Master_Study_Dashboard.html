🎯 Specificity Formula: (a, b, c, d)

a: Inline Style (style="...") [Weight: 1000] b: ID Selector (#main-nav) [Weight: 100] c: Class, Attribute, Pseudo-class (.btn) [Weight: 10] d: Element, Pseudo-element (div, ::after) [Weight: 1] Examples: • #header .menu-link:hover -> (0, 1, 2, 0) = Score 120 • .nav .nav-item -> (0, 0, 2, 0) = Score 20 • div p -> (0, 0, 0, 2) = Score 2

📦 CSS Box Model (Standard vs border-box)

+-----------------------------------------------------+ | MARGIN (Transparent outer space) | | +-----------------------------------------------+ | | | BORDER (Visible perimeter) | | | | +-----------------------------------------+ | | | | | PADDING (Inner breathing room) | | | | | | +-----------------------------------+ | | | | | | | CONTENT (Width x Height) | | | | | | | +-----------------------------------+ | | | | | +-----------------------------------------+ | | | +-----------------------------------------------+ | +-----------------------------------------------------+ * Universal Reset: *, *::before, *::after { box-sizing: border-box; }

📐 1D Flexbox vs 2D CSS Grid Layouts

FLEXBOX (1D Axis Layout): • Main Axis: justify-content (flex-start | center | space-between) • Cross Axis: align-items (flex-start | center | stretch) CSS GRID (2D Simultaneous Row & Column Layout): • Container: display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); • Gap: gap: 1.5rem;
