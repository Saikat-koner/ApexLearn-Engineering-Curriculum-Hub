Mastering HTML, CSS & JavaScript Web Publishing — Laura Lemay, Rafe Colburn, Jennifer Kyrnin (BPB)
Ch 1 & 2 (Client-Server & HTML5 Structure): HTTP request-response cycle, MIME types, DOCTYPE declarations, head metadata, vector SVG vs raster images, semantic structuring (header, nav, main, article, section, aside, footer).
Ch 5 & 6 (Forms & Accessibility): HTML5 input types, form validation attributes (pattern, required), ARIA roles, semantic data tables (thead, tbody, tfoot, colspan, rowspan).
🎯 Exam Focus: Draw Client-Server HTTP cycle, HTML5 page structure tree, and write accessible forms with regex.
HTML5 Black Book (Covers CSS3, JavaScript, XML, AJAX, jQuery) — DT Editorial Services (Wiley)
Ch 7, 8 & 9 (CSS Engine & Selectors): CSS Specificity formula (a,b,c,d), Combinators, Pseudo-classes (:hover, :focus, :nth-child()), Pseudo-elements (::before, ::after).
Ch 10 & 11 (Box Model, Flexbox & Grid): Standard vs border-box model math, Positioning (static, relative, absolute, fixed, sticky), 1D Flexbox axis alignments, 2D CSS Grid (repeat, minmax, auto-fit), CSS Variables, Keyframes.
🎯 Exam Focus: Calculate Specificity math tuples, draw the CSS Box Model, and contrast Flexbox vs Grid with axis diagrams.
Eloquent JavaScript (4th Ed) — Marijn Haverbeke / MDN Web Docs
Ch 2, 3 & 4 (JS Engine & Scopes): Execution Context, Call Stack, Scoping (var vs let/const), Hoisting, Closures, Higher-Order functions (map, filter, reduce), Object destructuring.
Ch 14, 15 & 18 (DOM & Browser APIs): DOM Tree, Event Bubbling vs Capturing, Event Delegation, Regex validation, localStorage vs sessionStorage vs Cookies, Fetch API with async/await, JSON handling.
🎯 Exam Focus: Draw JS Event Loop / Call Stack, demonstrate Event Delegation, and write async Fetch API error-handled code.
